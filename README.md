# AI Decision Network Simulator
Unit V – Uncertain Knowledge and Reasoning (static site: HTML, CSS, JS).

## Deploy on Render (Static Site)
Repo root must contain: package.json, build.js, index.html, css/, js/
- Build Command:     npm install && npm run build
- Publish Directory: dist
(If these files are inside a sub-folder of the repo, set "Root Directory" to that folder.)

## Run locally
npm run build   (creates dist/)   then open dist/index.html
